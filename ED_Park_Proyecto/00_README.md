# ED Park — Proyecto de Infraestructura de Telecomunicaciones

## Descripción General

Este proyecto presenta el desarrollo de un **parque logístico de productos electrónicos (ED Park)** ubicado en Matanzas, Cuba, con una superficie de 0.5 hectáreas (5,000 m²). El objetivo es implementar una infraestructura de telecomunicaciones completa basada en estándares GOST e internacionales para soportar operaciones logísticas automatizadas.

- **Ethernet (IEEE 802.3)** e **Industrial Ethernet** determinista
- **Беспроводные mesh-сети** — Redes mesh inalámbricas
- **Выделенные сети IoT** — Redes IoT dedicadas (Zigbee)
- **Точки доступа** y **промышленные коммутаторы** — APs y switches industriales
- **Резервированные каналы связи** — Canales redundantes
- **Серверы связи**, **шлюзы** y **edge-шлюзы** — Servidores, gateways y edge gateways
- **Sincronización de tiempo** — PTP (IEEE 1588)
- **M2M / V2X / V2I** — Comunicación entre máquinas y con la infraestructura, para AGV
