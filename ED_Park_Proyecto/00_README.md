# ED Park - Proyecto de Infraestructura de Telecomunicaciones

## Descripción General

Este proyecto presenta el desarrollo de un **parque logístico de productos electrónicos (ED Park)** ubicado en Matanzas, Cuba, con una superficie de 0.5 hectáreas (5,000 m²). El objetivo es implementar una infraestructura de telecomunicaciones completa basada en estándares GOST e internacionales para soportar operaciones logísticas automatizadas.
